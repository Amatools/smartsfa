# ERP Logos (SVG)

Store SVG logos for ERP connectors in this folder.

## Naming convention

- `sankhya.svg`
- `omie.svg`
- `bling.svg`
- `tiny.svg`

Use lowercase names with `-` when needed.

## Usage guideline

- Keep logos with transparent background when possible.
- Prefer square or near-square viewport for consistent card rendering.
- If an ERP has no logo yet, fallback to text initials in UI.
